# NFL & CFB Stat Leaders

A static site showing NFL and college football statistical leaders, broken out
by position, for ~60 stat categories. Data comes from ESPN's public stats
pages and is regenerated by a Node script (not hand-maintained).

## Structure

- `src/categories.js` — the full list of leaderboards (label, position filter,
  which underlying stat feeds it).
- `src/fetch-espn.js` — pulls NFL leaders from ESPN's JSON stats API
  (`site.web.api.espn.com`), which works fine and sorts correctly.
- `src/fetch-espn-cfb.js` — pulls CFB leaders. ESPN's JSON API's sort is
  **broken** for college football (every sort returns `-` placeholders), so
  this instead scrapes the real stats webpage (`espn.com/college-football/stats/player`),
  which has the same data correctly sorted, embedded as JSON in the page
  (`window['__espnfitt__']`). It also filters server-side to Power 4
  conferences (ACC, Big 12, Big Ten, SEC) + Notre Dame — the set Yahoo
  Fantasy College Football uses — via ESPN's own conference `group` id filter,
  rather than post-filtering a "whole country" list.
  - ESPN's site sits behind bot-protection that blocks plain Node HTTP
    requests entirely (even proxied), so this module shells out to `curl`
    instead. It also blocks a full, well-formed Chrome user-agent string
    outright (likely a TLS-fingerprint mismatch check — curl claiming to
    *be* Chrome without Chrome's TLS signature) while a short, generic
    user-agent goes through every time, so that's what's used.
- `src/generate.js` — orchestrates both fetchers and writes one JSON file per
  leaderboard into `docs/data/nfl/` and `docs/data/cfb/`, plus
  `docs/data/manifest.json`.
- `docs/` — the static frontend (`index.html` + `app.js` + `styles.css` +
  `data/`) — this whole folder is what gets deployed/hosted.
- `reference/cfb-power4-teams.json` — a snapshot of the Power 4 + Notre Dame
  team list (for reference/documentation only; the actual filtering uses
  ESPN's own conference `group` ids, not this file).

## Regenerating data

```
node src/generate.js
```

Takes about 10-15 seconds. It's meant to be run on a schedule (see below) —
every run overwrites `docs/data/**/*.json` with fresh numbers for the
current season.

## Known data gaps

Two categories the original spec asked for can't be built from any free
public source:

- **Sacks Allowed (OL)** — not tracked publicly by ESPN or anywhere else
  we could find; it's a PFF-style paid metric. Shown in the UI with an
  explanation rather than silently omitted.
- **Fumbles Recovered — CFB only** — the field simply isn't present in
  ESPN's public CFB stats tables (NFL's *is* available and works fine).

Also, CFB defensive linemen are sometimes tagged generically "DL" by ESPN
instead of DT or DE — those players are excluded from both the DT and Edge
boards rather than guessed into one, so those two boards may undercount
slightly.

## Setting up auto-refresh

To keep this live, schedule `node src/generate.js` to run periodically
(e.g. every few hours during the season) in whatever environment hosts this
repo, then commit + push the regenerated `data/` files.
