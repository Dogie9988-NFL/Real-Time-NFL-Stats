# NFL & CFB Stat Leaders

A static site showing NFL and college football statistical leaders, broken out
by position, for ~60 stat categories, plus a live scoreboard. Data is pulled
from public APIs and regenerated by Node scripts (not hand-maintained).

## Structure

- `src/categories.js` — the full list of leaderboards (label, position filter,
  which underlying stat feeds it).
- `src/fetch-espn.js` — pulls NFL leaders from ESPN's JSON stats API
  (`site.web.api.espn.com`), which works fine and sorts correctly, and isn't
  rate-limited or blocked from anywhere (including GitHub Actions runners).
- `src/fetch-cfbd.js` — pulls CFB leaders from the
  [CollegeFootballData.com](https://collegefootballdata.com) API. We used to
  scrape ESPN's CFB stats webpage instead (ESPN's own JSON API returns `-`
  placeholders for every college-football stat value — a real bug on their
  end, not something we can fix), but that scrape is blocked outright when
  run from GitHub Actions' cloud IPs, even though it works from a normal
  network. CFBD is a real public API with no bot-protection to route around,
  but its free tier is capped at **1,000 calls/month**, so this fetches every
  stat category in a single unfiltered call (omitting the `category` filter
  returns all of them) to spend exactly 1 call per run. Needs a
  `CFBD_API_KEY` env var (get a free one at https://collegefootballdata.com/key).
- `src/fetch-live.js` / `src/generate-live.js` — today's live scores and each
  game's current passing/rushing/receiving leader, written to
  `docs/data/live.json`.
- `src/generate.js` — orchestrates the season-stats fetchers and writes one
  JSON file per leaderboard into `docs/data/nfl/` and `docs/data/cfb/`, plus
  `docs/data/manifest.json`. Takes an optional CLI arg (`nfl` or `cfb`) to
  refresh just one league — see "Setting up auto-refresh" for why.
- `docs/` — the static frontend (`index.html` + `app.js` + `styles.css` +
  `data/`) — this whole folder is what gets deployed/hosted.
- `reference/cfb-power4-teams.json` — Power 4 + Notre Dame team list keyed by
  ESPN team id, used by `fetch-live.js` for the scoreboard.
- `reference/cfb-power4-teams-cfbd.json` — the same team list keyed by CFBD's
  school names (with abbreviation + conference), used by `fetch-cfbd.js`.
  Static rather than fetched live, since conference membership only changes
  in the off-season and every API call counts against the 1,000/month quota;
  regenerate it from CFBD's `/teams/fbs` endpoint if realignment happens.
- `src/fetch-espn-cfb.js` / `src/generate-fantasy.js` / `src/generate-live-fantasy.js`
  / `src/fantasy-scoring.js` / `src/fetch-espn-category.js` /
  `src/fetch-live-fantasy.js` — the Fantasy tab (season + live fantasy
  scoring, trade calculator). Its CFB fetch still uses the old ESPN
  stats-webpage scrape (`fetch-espn-cfb.js`), which **has the same
  GitHub-Actions-blocking problem `fetch-cfbd.js` above was written to fix**,
  and doesn't yet have `generate.js`'s "never overwrite good data with an
  empty fetch" safety net either — so CFB fantasy boards are likely to go
  silently stale or get wiped the same way the main CFB leaderboard did
  before that fix. Not addressed here since it's a separate feature; worth
  migrating to `fetch-cfbd.js` the same way if that happens.

## Regenerating data

```
node src/generate.js        # both leagues
node src/generate.js nfl    # NFL only
node src/generate.js cfb    # CFB only (needs CFBD_API_KEY)
node src/generate-live.js   # live scoreboard
```

A run never overwrites a board with empty/failed data — if a stat pool comes
back empty (blocked fetch, API outage, bad key), that board's file is left
untouched and its previous manifest entry carries forward instead.

## Known data gaps

- **Sacks Allowed (OL)** — not tracked publicly anywhere we could find; it's
  a PFF-style paid metric. Shown in the UI with an explanation rather than
  silently omitted.
- **Forced Fumbles — CFB only** — CFBD doesn't track this stat at all (NFL's
  *is* available, from ESPN, and works fine).

Also, CFB defensive linemen are sometimes tagged generically "DL" instead of
DT or DE — those players are excluded from both the DT and Edge boards rather
than guessed into one, so those two boards may undercount slightly.

## Setting up auto-refresh

Three scheduled GitHub Actions workflows keep this live:

- `.github/workflows/refresh-live.yml` — every 5 minutes, no quota concerns.
  Also runs `generate-live-fantasy.js`.
- `.github/workflows/refresh-stats-nfl.yml` — every 5 minutes, no quota
  concerns (ESPN's JSON API). Also runs `generate-fantasy.js` (see the
  Fantasy-tab note above on its CFB half).
- `.github/workflows/refresh-stats-cfb.yml` — hourly, because CFBD's free
  tier caps at 1,000 calls/month and this repo only spends 1 call per run
  (~730/month at this cadence, leaving headroom for manual runs). Requires a
  `CFBD_API_KEY` repository secret (Settings → Secrets and variables →
  Actions). Push more often only if you upgrade past the free CFBD tier.
